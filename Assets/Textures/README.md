# Textures

Izometrické 2D obrázky pre Paradise Tycoon, rozdelené podľa obsahu:

- `Buildings/`: hotel, reštaurácia, plážový bar, bungalov, bazén a spa. Každý typ má štyri levely; príklad: `Buildings/Hotel/hotel_L1.png` až `hotel_L4.png`.
- `Environment/`: základ ostrova, more a pobrežie, vegetácia, skaly, chodníky a oblasti na rozšírenie.
- `Harbor/`: mólo a dve lode.
- `Props/`: plážové vybavenie, lavička, lampa, kvetináč a oplotenie.
- `Characters/Guests/TouristMale/`: statická postava turistu a chôdza v ôsmich smeroch.

Sada obsahuje 126 PNG súborov. Zachovávajú pôvodné rozlíšenie a priehľadnosť; podklad mora je nepriehľadný. Názvy súborov používajú angličtinu bez diakritiky.

Návod a údaje k animácii sú v `Characters/Guests/TouristMale/Walk/`. Animácia je pracovná sada pre prototyp a môže vyžadovať ručné doladenie prechodov kroku.
